Project synopsis

My final Instrument Milky Way is a browser-based musical toy built around the solar system. The Sun sits on the left as a big start/stop button, and eight planets are laid out across the screen. Tapping a planet plays its note, sends coloured ripples out from it and switches it on for the loop. Tapping the Sun starts a loop that plays every planet that is switched on, one after another, from Mercury to Neptune. To change the pitch, tapping the top or bottom of a planet makes its note higher or lower, and a panel along the bottom moves every planet up or down in five steps. All notes come from a pentatonic scale, so any combination a child makes sounds pleasant.

It is built with HTML, CSS, SVG and JavaScript, using Tone.js for the sound.

Design scenario

Prompt Design a way for young children with minimal language skills to explore music.

Context: Browser based musical instruments offer users the ability to dynamically perform music and explore complex audio design. While these interactions allow for a depth of control they can be intimidating for many adult users, let alone you children whose language skills are still developing.

How the finished project responds to the scenario

  • Very little reading needed. The instructions are three short steps in a slim strip at the top. Each step has a number, an icon and one short sentence. The pitch panel shows the current pitch as a word and as a row of dots, so a child can see it as well as hear it.
  • Nothing can sound wrong. Every note comes from a pentatonic scale, so any combination of planets sounds pleasant.
  • Every touch gets a reaction. Sound, ripples, glowing planets and twinkling stars all respond straight away, which teaches cause and effect.
  • Big, forgiving targets. The planets and the Sun are large, tapping a planet again just switches it off, and the pitch dots have 44px touch areas.
  • A calm screen. The instruction and pitch panels are slim and see-through so the planets stay the focus, and nothing bounces or pulses to compete for attention before the child has touched anything.
  • Adaptive layout. The sky scales to any screen size, the instruction and pitch panels wrap onto extra lines on narrow screens, and animations are reduced for people who prefer less motion.

Documentation

The core interactive features of the instrument are :

  • Tap a planet to play it and switch it on or off for the loop.
  • Tap the top or bottom of a planet to make its note higher or lower.
  • Tap the Sun to start and stop the loop.
  • Pitch panel shifts every note up or down in five steps.
  • Three short steps at the top explain how to play.
  • Glowing stars react to touch and ripples.

The documentation below covers each feature, my extended technique, and the design system (colour, type, components and rules).

Core interactive features

The instrument is three files: final-instrument.html (the SVG solar system and the panels), final-instrument.style.css (look and animation) and final-instrument.script.js (sound and behaviour).

1. Tap a planet: note, ripples and on/off

Each planet is an SVG circle with a click listener. A tap plays the planet's current note, draws the ripples, and adds the planet to (or removes it from) a Set of active planets. Planets that are on keep a glow, so a child can see which ones will play in the loop. 

planet.addEventListener("click", async (event) => {
  await Tone.start();   // browsers need a tap before audio can start
  synth.triggerAttackRelease(noteFor(id), "8n");
  ripplePlanet(planet);
  // add or remove the planet from activePlanets, and toggle the .on class
});

2. Pitch from where you tap

The tap position is converted into SVG coordinates and then into a number from 0 (top of the planet) to 1 (bottom). That becomes an offset of -2 to +2 notes along the scale, so the top gives a higher note and the bottom a lower one. Each planet remembers its own offset, and the loop uses it too. 

const svgPoint = point.matrixTransform(sky.getScreenCTM().inverse());
const fraction = (svgPoint.y - (cy - r)) / (2 * r);   // 0 = top, 1 = bottom
planetOffset[id] = Math.round((0.5 - height) * 4);    // -2 ... +2

3. Pitch panel: Lower, Higher and five dots

The panel along the bottom moves every planet up or down together. The state is one number, pitchStep, from -2 to +2, and each step moves a note three places along the pentatonic scale, which keeps everything in key. The Lower and Higher buttons and each of the five dots all call the same function. It updates the pitch word, fills the dots and line up to the current step, and plays a short preview note so the change can be heard straight away. 

function noteFor(id) {
  let index = planetBase[id] + planetOffset[id] + pitchStep * 3;
  index = Math.max(0, Math.min(scale.length - 1, index));
  return scale[index];
}

4. Ripples in each planet's colour

ripplePlanet() creates three SVG circles at the planet's position, each starting 0.25 seconds after the last. A CSS animation scales them up and fades them out, and each ring removes itself when its animation ends. The ring colour is read from a CSS custom property (--glow-halo) set on each planet, so the colours are defined in one place.

5. Twinkling stars that react to the music

Seventy small stars are created in JavaScript with random positions, sizes and twinkle speeds. Whenever a planet plays, a handful of them flash in that planet's colour. The glow is kept small and tight so the background stays calm.

6. Intro pop-up and audio start

A <dialog> opens when the page loads to warn that the instrument makes noise. Browsers also block audio until the user does something, so every tap calls Tone.start() before playing.

Extended technique: scheduling sound and visuals with Tone.js

Tapping the Sun starts and stops Tone.Transport. A Tone.Loop runs every eighth note and visits one planet per step, from Mercury to Neptune, playing it only if it is switched on. Sound and picture are kept together in three ways:

  • The loop plays through its own synth (loopSynth), so it can't clash with notes the child plays by hand.
  • Notes are scheduled at the exact time the loop provides, so the rhythm stays steady even if the page is busy.
  • Tone.Draw.schedule triggers each ripple at the moment its sound plays, instead of a little earlier when the code runs.
const loop = new Tone.Loop((time) => {
  const id = planetOrder[step % planetOrder.length];

  if (activePlanets.has(id)) {
    loopSynth.triggerAttackRelease(noteFor(id), "16n", time);
    Tone.Draw.schedule(() => ripplePlanet(document.getElementById(id)), time);
  }
  step++;
}, "8n");

Design system

Four things hold the look together: dark space, a few bright accents, one rounded font, and see-through panels that keep the planets in focus.

3. Components

Planet and Sun

SVG circle with a radial gradient for depth. Glows on hover, glows more when switched on.

Step strip

One slim see-through bar with three steps. Each has a yellow number, an icon, a title and one sentence.

Pitch panel

The pitch word, Lower and Higher buttons, and a five-dot slider. The current step is the big white dot.

Ripple

Three rings in the planet's colour that grow and fade out. Shown for every note.

Star

Small white dot that twinkles. Flashes in a planet's colour when it plays, with a small tight glow.

Intro dialog

Dark box with a white border and a purple OK button. Warns the grown-up about the sound.

4. Rules

Layout

Steps on top, solar system in the middle, pitch along the bottom. The planets get the most room.

Shape

Rounded panels (18px) with a thin pale border. Simple line icons, no emoji.

Motion

Only ripples, twinkling stars and a gentle Sun pulse while the loop plays. Reduced when the device asks for less motion.

Access

Pitch controls are real buttons with labels. Touch areas for the dots are 44px.
